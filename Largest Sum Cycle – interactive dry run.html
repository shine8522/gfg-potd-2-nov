Why visited[] alone fails

visited[] answers: “seen anywhere, ever?” pathVis[] answers: “on the traversal happening right now?” A cycle needs the second one.

Complexity, derived

Outer loop: N iterations. A node is marked vis=1 once and never unmarked, so across all traversals the while-loop pushes at most N nodes in total. The start search, the sum loop and the pathVis reset each touch only nodes of one path, and each node sits in exactly one path. So total work ≈ N (walk) + N (search) + N (sum) + N (reset) + N (skips) = O(N).

One traversal can cost O(N) in the worst case, but that cost is shared: nodes it consumes are skipped later. Nested loops do not automatically mean O(N²) – what matters is how many times each node is touched in total.

Space: vis, pathVis and path are each at most N → O(N) auxiliary.
